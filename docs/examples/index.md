# Examples

Practical, runnable Rhodesia code, organized by topic. Every page collects
several short programs that you can copy into a `.rho` file and run.

## Sections

1. [Basics](basics.md) — Hello World, arithmetic, vectors, matrices, control flow.
2. [Data Structures](data-structures.md) — Vector and matrix operations.
3. [Collections](collections.md) — `set`, `tuple`, `record`, `match`.
4. [I/O](io.md) — File operations, CSV, user input.
5. [Machine Learning](machine-learning.md) — Regression, k-means clustering.
6. [Modules](modules.md) — Code organization with `include`.

All examples assume a working installation. See
[Getting Started](../getting-started.md) and
[Installation & Editor Setup](../installation.md) if you have not installed
Rhodesia yet.
