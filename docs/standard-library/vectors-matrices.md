# Vectors & Matrices — Legacy Reference

> **Note:** This page is kept for backward-compatibility with external
> links. The vector / matrix helpers have been split into dedicated pages:
>
> - [`vector`](vector.md) — immutable vector helpers (append, remove,
>   reverse, insert, size).
> - [`matrix`](matrix.md) — immutable matrix helpers (append_row,
>   append_col, remove_row, remove_col, rows, cols, size).
>
> For vector / matrix math (transpose, inverse, dot, norm, etc.) see the
> [`math`](math.md) module.
>
> For higher-level linear algebra (determinant, trace, decompositions,
> projections, rotations) see the user-space
> [`libs/math`](libs-math.md) library.
