# Math Library Project

This folder contains a comprehensive math library project demonstrating Rhodesia's capabilities for building mathematical libraries.

## Folder Structure

```
math_library/
├── README.md                  # This file
├── main.rho                   # Main program
├── core/                      # Core mathematical functions
├── linear_algebra/            # Linear algebra operations
├── numerical/                 # Numerical methods
└── statistics/                # Statistical functions
```

## Components

### main.rho
The main program demonstrating:
- Library usage
- Function integration
- Example calculations
- Library testing

### core/
Core mathematical functions:
- `core.rho` - Fundamental math operations
- `trigonometry.rho` - Trigonometric functions

### linear_algebra/
Linear algebra operations:
- `matrices.rho` - Matrix operations
- `vectors.rho` - Vector operations
- `decompositions.rho` - Matrix decompositions

### numerical/
Numerical methods:
- `integration.rho` - Numerical integration
- `optimization.rho` - Optimization algorithms
- `root_finding.rho` - Root finding algorithms

### statistics/
Statistical functions:
- `descriptive.rho` - Descriptive statistics
- `probability.rho` - Probability functions
- `regression.rho` - Regression analysis

## Key Concepts Covered

- Library design and organization
- Mathematical function implementation
- Linear algebra operations
- Numerical methods
- Statistical computing
- Module-based library structure
- Code organization best practices

## Usage

```bash
# Run the math library main program
./rhodesia examples/proyects/math_library/main.rho
```
