# Rhodesia Language Examples

This folder contains a comprehensive collection of examples demonstrating the Rhodesia programming language capabilities.

## Folder Structure

```
examples/
├── README.md                  # This file
├── basic/                     # Basic language features
├── control_flow/              # Control flow examples
├── data_structures/          # Vector and matrix operations
├── machine_learning/         # Machine learning examples
├── modules/                   # Module system examples
├── performance/              # Performance testing
├── proyectos/                 # Project examples
├── slicing/                  # Array slicing examples
├── stats/                    # Statistical computing examples
└── *.rho                     # Miscellaneous examples
```

## Getting Started

For beginners, start with the [basic examples](basic/README.md) to learn the fundamentals of Rhodesia.

## Running Examples

To run any example, use the Rhodesia interpreter:

```bash
./rhodesia examples/path/to/example.rho
```

Or use the REPL mode to experiment:

```bash
./rhodesia
```
