# Slicing Examples

This folder contains examples demonstrating Rhodesia's array slicing capabilities.

## Examples

### slicing_demo.rho
Demonstrates basic slicing operations including:
- Vector slicing
- Matrix slicing
- Range-based slicing
- Index-based slicing

### slicing_advanced.rho
Showcases advanced slicing techniques including:
- Multi-dimensional slicing
- Complex slice patterns
- Slice combinations
- Practical slicing applications

## Key Concepts Covered

- Array slicing syntax
- Vector and matrix slicing
- Range specifications
- Index calculations
- Memory-efficient slicing
- Multi-dimensional slicing

## Usage

```bash
# Run basic slicing demo
./rhodesia examples/slicing/slicing_demo.rho

# Run advanced slicing demo
./rhodesia examples/slicing/slicing_advanced.rho
```
