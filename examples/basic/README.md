# Basic Examples

This folder contains introductory examples to get you started with Rhodesia.

## Examples

### hello.rho
A comprehensive introduction to Rhodesia covering:
- Basic output with `println`
- Variables (integers, floats)
- Vectors (creation, operations like sum, mean, norm)
- Matrices (creation, basic operations)
- Mathematical functions (sqrt, exp, etc.)
- Control flow (if-else, for loops)
- Functions (definition and calling)

Run with: `rhodesia examples/basic/hello.rho`
