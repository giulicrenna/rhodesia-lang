# Simple Module Examples

This folder contains basic examples of Rhodesia's module system.

## Examples

### simple_math.rho
A simple math module demonstrating:
- Basic mathematical functions
- Module structure
- Function exports
- Simple calculations

### stats.rho
A statistics module demonstrating:
- Statistical functions
- Data analysis functions
- Statistical computations
- Module organization

### main.rho
Main program using the simple modules:
- Importing modules
- Using module functions
- Combining modules
- Basic module usage patterns

### test_simple.rho
Tests simple module functionality:
- Module loading
- Function calling
- Error handling
- Module testing

## Key Concepts Covered

- Module creation and structure
- Function definition and export
- Module importing
- Module usage patterns
- Basic module testing
- Error handling in modules

## Usage

```bash
# Run the main program using simple modules
./rhodesia examples/modules/simple/main.rho

# Run simple module tests
./rhodesia examples/modules/simple/test_simple.rho
```
