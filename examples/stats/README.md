# Statistics Examples

This folder contains examples demonstrating Rhodesia's statistical computing capabilities.

## Examples

### stats_basic.rho
Demonstrates basic statistical operations including:
- Mean, median, mode calculations
- Standard deviation and variance
- Basic statistical functions
- Data summarization

### statistics_demo.rho
Showcases statistical computing including:
- Descriptive statistics
- Probability distributions
- Statistical testing
- Data analysis

### math_module_demo.rho
Demonstrates mathematical functions for statistics including:
- Mathematical operations
- Statistical functions
- Data transformations
- Numerical computations

## Key Concepts Covered

- Statistical functions
- Data analysis
- Probability calculations
- Mathematical operations
- Data visualization preparation
- Statistical modeling

## Usage

```bash
# Run basic statistics example
./rhodesia examples/stats/stats_basic.rho

# Run statistics demo
./rhodesia examples/stats/statistics_demo.rho
```
